研究背景與核心目標：本論文專注於「零樣本語音情緒識別（Zero-Shot Speech Emotion Recognition, SER）」，探討跨語料庫（Cross-Corpus）環境下的模型泛化能力。核心機制著重於透過語意嵌入（Semantic Embedding）空間對照與聲學特徵提取，降低不同資料集間的分佈偏差，提升未見類別的識別效能。
工程瓶頸與架構重構：既有實驗流程受限於演算法腳本分散，自原始音訊前處理、高維特徵提取、PyTorch 模型訓練至驗證評估皆需手動分段執行，導致單次實驗耗時長達 30 分鐘，且檔案傳遞與參數設置極易衍生人為操作失誤。
端到端自動化效益：為加速模型迭代，採用 Python 實作端到端自動化流水線（End-to-End Pipeline），將特徵提取、跨語料驗證與數據視覺化整合為一鍵執行機制。單次實驗驗證時間由 30 分鐘大幅縮減至 5 分鐘，流程效能提升 83% 以上。
模型架構與特徵工程：系統整合開源深度學習預訓練架構與語意表徵策略，實作多種 Embedding 特徵對照實驗。評估指標涵蓋準確率（Accuracy）、混淆矩陣與跨語料對照分析，確保泛化效能具備統計顯著性。
技術棧與系統部署環境：核心演算法基於 Python 與 PyTorch 深度學習框架實作，資料前處理採用 NumPy 與 Pandas；開發環境依托 Linux 作業系統，並運用 Docker 容器化技術封裝執行環境與相依套件，確保實驗的可重現性（Reproducibility）與 Git 版本控管。
